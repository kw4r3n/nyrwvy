# Bytes — 2026-10-26

**Status:** Complete for Decision 1 of the [design note](../plans/bytes-and-buffers.md). The [`Bytes` value type](../decisions/bytes-domain.md) and its ten total operations are implemented through authoring, validation, snapshot JSON and records (schema 23), Typed Semantic IR, Execution IR, the viewer, the C# backend (`NyBytes`, copying on every update) and `runPure`. In-place updates are not part of this step.

Baseline: nyrwvy `78d92a4` (main after #500) plus this change.

## What was checked

The fast Core suite covers, in `BytesTests`:

- recipe type errors for every operand position, a Bytes result declared as String or List, and wire shapes (an operand on `bytesEmpty`, `left`/`right` on `bytesAppend`, a missing `value` or `length`, a `bytesLiteral` kind) as protocol errors;
- persisted-graph validation with `BytesOperandTypeMismatch`, `ValueEqual` over Bytes, and the schema version: a Bytes node, or the type alone in a signature, needs 23, and a graph without Bytes keeps the baseline;
- all ten kinds through name-resolved authoring, snapshot JSON (written at 23) and record round trips with an unchanged fingerprint, rejection of the same document declared at 22, reopen, Typed Semantic IR, Execution IR, the viewer (`Source`/`Index`/`Item` roles and labels) and the emitted C# (`NyBytes` and each method the emitter calls);
- malformed run values (odd digit count, non-hex, `0x` prefix, space, number, null, missing `hex`, `value` instead of `hex`, extra field, flat `itemKind`, and the same mistakes in the plain form) as protocol errors, and Bytes passed for a String as `RunArgumentTypeMismatch`.

The Extended suite compiles the emitted program and runs it through `runPure`, comparing each result with an independent F# model of the rules:

- `BytesFill` for lengths `Int64.MinValue`, -5, -1, 0, 1, 3 and values 0, 1, 255, 256, 257, -1, -255, -256, 300, `Int64.MinValue`, `Int64.MaxValue` (low 8 bits; negative length gives empty);
- for samples of length 0, 1, 3 and 300: `BytesLength`, `BytesConcat` with empty on either side and with two bytes, `BytesToLatin1`, `ValueEqual` against a copy, `BytesAppend` of every value above, and for positions `Int64.MinValue`, -2, -1, 0, 1, 2, 3, 299, 300, 301, `Int64.MaxValue`: `BytesGet` (None outside the range), `BytesSet` of -1 (255 inside, unchanged outside) and `BytesSlice` against six end bounds (clamping, `end <= start` empty);
- unequal lengths and contents compare unequal; `BytesEmpty` is empty;
- `BytesFromLatin1` of `""`, `"abc"`, U+0000/U+00FF/U+0100, `"é€😀"`, lone surrogates and 300 characters: one byte per code point, 0xFF above U+00FF, a pair counted once;
- a constant built as `BytesFromLatin1` of a String literal, and a `BytesSet` copy concatenated with its unchanged source (`7a 62 61 62`);
- the wire forms: tagged `{"kind":"bytes","hex":"00FF"}` in, `{"kind":"bytes","hex":"00ff7f"}` out; the plain hex strings `"00ff"` and `"7F"` in; the empty value `""`; and a mismatch report that prints the actual hex.
