# Documentation archive

**Status:** Historical

This directory contains frozen or superseded Nyrwvy documentation (including material written while the project was named NyamNyam) kept for design history, implementation evidence, and auditability.

Archive material is **not authoritative for current behavior**. Start from the maintained [documentation portal](../docs/README.md) for current concepts, reference, specifications, decisions, plans, and verification records.

## Authority rule

When archived prose conflicts with maintained documentation, tests, or the current implementation, use the current maintained sources appropriate to the question. Historical disagreement is expected and is not repaired in place merely to make old records look current.

## Organization

Archive material should be grouped one level deeper by coherent phase, event, or time period when a flat archive would become noisy. Collections include:

- [`2026-08-pre-reorg/`](2026-08-pre-reorg/) — the complete documentation tree immediately before Issue #30 reorganized current documentation by purpose.

- [`2026-09-general-purpose-programming/`](2026-09-general-purpose-programming/) — the original general-purpose roadmap and staged implementation history (Japanese; the original working document, superseded by the English [general-purpose programming roadmap](../docs/plans/general-purpose-programming-roadmap.md)), separated from the maintained current status on 2026-09-26.

## Retention

Ordinary documentation maintenance may move clearly inactive material into this archive without deleting its history. Deleting archived records is a separate maintenance action and requires explicit confirmation.
